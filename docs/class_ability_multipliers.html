Detailed Description

Ability multiplier container, stores a list of multipliers/modifiers that is passed to an ability to modify its behaviour.

Parameters
GlobalMultipliera multiplier that applies equally to every effect.
CooldownMultipliera multiplier that only decreases the cooldown of a projectile.
AccuracyMultipliera multiplier to increase the accuracy of an ability.
BonusProjectilesa fixed amount of bonus projectiles to fire. (not yet implemented).

when implementing these multiply the base value by (1 + GlobalMultiplier + <relevant multipliers> + ect)

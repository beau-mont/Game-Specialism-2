Detailed Description

Payload modifier container, this is passed to payloads so they can implement what they need. When adding new multipliers add the new variable here and implement it where needed.

Parameters
GlobalMultipliera multiplier that applies equally to every effect.
DamageMultipliera multiplier that only increases damage of a payload.
RadiusMultipliera multiplier to increase the radius of AOE payloads.
BurnMultipliera multiplier to increase burn stacks. (not yet implemented).

when implementing these multiply the base value by (1 + GlobalMultiplier + <relevant multipliers> + ect)

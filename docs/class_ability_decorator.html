Detailed Description

AbilityDecorator combines functionality from a list of AbstractPayload's and an AbstractAbilityBehaviour. It also passes modifiers to them that they can interpret in their own way.

Parameters
projectileNamethe name of this projectile, only used for debugging.
payloadsan array of ScriptableObject's that inherit AbstractPayload, they describe what to do when hitting something.
damagethe base damage of this ability
abilityBehavioura ScriptableObject's that inherits AbstractAbilityBehaviour, this is used to describe how the ability moves.
hitEffectsan array of VFX to spawn when the ability hits something.
payloadMultipliersa data container that stores multipliers to modify AbstractPayload's behaviour.
AbilityBehaviourMultipliersa data container that stores multipliers to modify AbstractAbilityBehaviour's behaviour.
ownerthe GameObject that fired the ability.
rbthe rigidbody attached to the ability
lifetimethe lifetime of the ability object, the ability object will disable itself after this amount of time has passed. set to zero for unlimited lifetime.
